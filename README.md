# 百戏奇牌

《百戏奇牌》是一款本地优先、简体中文的网页扑克构筑游戏。当前版本提供一条可完整通关的确定性八幕演出：每幕包含小幕、大幕与班主，支持跳幕取签、牌型计分、奇牌效果、幕间赏银、夜市交易、卡包、永久木牌、压轴胜利与第九幕无尽加演。

项目只参考扑克肉鸽的玩法结构，使用自己的名称、规则代码、种子、存档格式和“午夜百戏”视觉体系，不与 Balatro 兼容。

## 本地运行

需要 Node.js 22.12 或更新版本，以及 npm。

```bash
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:4173>。建议使用 1280×720 或更大的桌面窗口；当前基线面向 Chrome、Edge 与 Safari，使用鼠标操作。

所有档案、牌局与设备设置都保存在当前浏览器的 IndexedDB 中，不需要账号、服务器或网络连接。导出档案会生成带版本与校验和的 JSON 文件；导入前会校验并提示覆盖对应档位。

```bash
npm run format:check  # 检查格式

```

## 游戏流程

1. 在甲、乙、丙三个档位之一建立档案，可填写固定种子后开局。
2. 在阵容页选择应战小幕、大幕或班主；小幕和大幕也可跳过，换取当前可见戏签。
3. 点击手牌选择最多五张牌，可按点数或花色整理；出牌计分，弃牌换牌。每次有效操作都先写入本地检查点。
4. 破幕后领取由破幕赏、余手赏和利息组成的固定收据，再进入夜市。
5. 夜市可购买或出售奇牌与消耗牌、重排奇牌、换摊、兑换永久木牌，也可拆开戏牌包、变牌包和奇牌包。
6. 击败第八幕压轴班主后选择谢幕或进入第九幕无尽加演；出牌耗尽且未达到目标则演出失败。

## 生产内容与审计页

新建牌局默认使用 V3 `catalog-baseline-3` 内容快照，采用基础牌组 D01 与第一阶难度 S01。当前非奇牌生产目录共 230 项：15 副牌组、8 阶难度、20 个挑战、32 块木牌、52 张消耗牌、24 枚戏签、30 个盲注、32 个卡包条目、8 种镶饰、4 种封印和 5 种版式。所有生产 ID 均使用 `bxqp:` 命名空间；旧 V1/V2 牌局会保留原有夹具快照并迁移到 V3，不会被新目录静默替换。

开发时可打开 <http://127.0.0.1:4173/?catalog-audit=1> 查看分页图鉴总账。该页面逐项显示简体中文身份、本地午夜百戏素材和独立焦点构图，不发起远程内容请求；可用 `?catalog-page=2` 直接打开指定页。
