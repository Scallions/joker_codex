# 百戏奇牌

《百戏奇牌》是一款本地优先、简体中文的网页扑克构筑游戏。当前仓库先交付一个可完整游玩的确定性纵切：三档本地档案、单盲注牌局、出牌与弃牌、牌型计分、奇牌与消耗牌、商店、胜负结算、自动保存及档案导入导出。

项目只参考扑克肉鸽的玩法结构，使用自己的名称、规则代码、种子、存档格式和“午夜百戏”视觉体系，不与 Balatro 兼容。

## 本地运行

需要 Node.js 22.12 或更新版本，以及 npm。

```bash
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:4173>。建议使用 1280×720 或更大的桌面窗口；当前基线面向 Chrome、Edge 与 Safari，使用鼠标操作。

所有档案、牌局与设备设置都保存在当前浏览器的 IndexedDB 中，不需要账号、服务器或网络连接。导出档案会生成带版本与校验和的 JSON 文件；导入前会校验并提示覆盖对应档位。

npm run format:check  # 检查格式

## 当前纵切操作

1. 在甲、乙、丙三个档位之一建立档案，可填写固定种子后开局。
2. 点击手牌选择最多五张牌；可按点数或花色整理。
3. 使用“出牌”计分，或使用“弃牌”换牌；每次有效操作都先写入本地检查点。
4. 达到盲注目标后进入商店，可购买、重掷、出售或调整奇牌顺序。
5. 离开商店完成试玩；若四次出牌后仍未达标则本局失败。

完整八底注流程、生产级内容目录、成长系统和最终美术属于后续任务，本纵切的内容 ID 均位于 `fixture:` 命名空间，不计入最终内容数量。
