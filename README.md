# 百戏奇牌

《百戏奇牌》是一款本地优先、简体中文的网页扑克构筑游戏。当前版本提供可完整通关的确定性八幕演出：每幕包含小幕、大幕与班主，支持跳幕取签、牌型计分、奇牌效果、幕间赏银、夜市交易、卡包、永久木牌、压轴胜利与第九幕无尽加演。普通战役、种子演出、挑战、八阶难度、教程、收藏、统计与 31 项百戏成就均在本地运行。

项目只参考扑克肉鸽的玩法结构，使用自己的名称、规则代码、种子、存档格式和“午夜百戏”视觉体系，不与 Balatro 兼容。

## 本地运行

需要 Node.js 22.12 或更新版本，以及 npm。

```bash
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:4173>。建议使用 1280×720 或更大的桌面窗口；当前基线面向 Chrome、Edge 与 Safari，使用鼠标操作。

所有档案、牌局与设备设置都保存在当前浏览器的 IndexedDB 中，不需要账号、服务器或网络连接。甲、乙、丙三个档位分别保存进度与活动牌局，音乐、音效、静音和演出速度属于设备级共享设置。导出档案会生成带版本与校验和的 JSON 文件；导入前会校验并提示覆盖对应档位。

## 在线游玩

正式版本发布在 <https://scallions.github.io/joker_codex/>。网站与本地开发使用相同的纯前端构建，不需要登录或连接游戏服务器。

IndexedDB 存档按网站来源（协议、主机和端口）隔离，URL 路径不参与隔离。因此 `http://127.0.0.1:4173` 与 `https://scallions.github.io` 拥有不同存档；只修改同一 GitHub Pages 主机下的仓库路径仍会访问同一来源的数据，而改用自定义域名会得到新的独立存档。跨来源切换前请先从旧地址导出档案，再在新地址导入。

## GitHub CI/CD

`main` 是受保护的生产分支。日常改动从功能分支提交 Pull Request；`Quality and Pages` 工作流会执行 `npm ci` 与完整的 `npm run check`。只有 `quality` 成功并合并到 `main` 后，完全相同的 `dist/` 构建产物才会自动部署到 GitHub Pages。

需要手动重新验证或发布时，在 GitHub 的 Actions 页面打开 `Quality and Pages`，点击 `Run workflow` 并选择 `main`。从其他分支手动运行只执行质量检查，不会发布生产站点。

完整 Chromium 与 WebKit 测试位于独立的 `Browser tests` 工作流，按需手动运行，不阻塞常规发布。失败后可在该次 Actions 运行的 Artifacts 区域下载 `playwright-diagnostics-*`，其中包含 Playwright HTML 报告、截图和 trace 等实际生成的诊断文件。

质量或部署失败时，先查看失败步骤的日志；不得跳过 `quality` 或直接绕过分支保护。需要回滚线上版本时，从最新 `main` 建立回滚分支，执行 `git revert <有问题的提交>`，推送并通过 Pull Request 合并；同一套 CI/CD 会验证并重新部署回滚结果。

## 游戏流程

1. 在甲、乙、丙三个档位之一建立档案，完成、跳过或稍后重温八步实机教程。
2. 选择普通战役、种子演出或已开放挑战；普通战役可选择已开放牌组与难度，种子演出可粘贴规范分享码。
3. 在阵容页选择应战小幕、大幕或班主；小幕和大幕也可跳过，换取当前可见戏签。
4. 点击手牌选择最多五张牌，可按点数或花色整理；出牌计分，弃牌换牌。每次有效操作都先写入本地检查点。
5. 破幕后领取由破幕赏、余手赏和利息组成的固定收据，再进入夜市。
6. 夜市可购买或出售奇牌与消耗牌、重排奇牌、换摊、兑换永久木牌，也可拆开戏牌包、变牌包和奇牌包。
7. 击败第八幕压轴班主后选择谢幕或进入第九幕无尽加演；出牌耗尽且未达到目标则演出失败。

## 生产内容与审计页

新建牌局使用 V7 `joker-catalog-3` 内容快照；新档案从基础牌组 D01 与第一阶难度 S01 开始，再通过本地进度开放其余内容。生产总目录共 380 项，其中包含 230 项非奇牌目录，以及 `bxqp:joker:001` 至 `bxqp:joker:150` 共 150 张可实际获得和结算的奇牌。每张奇牌都有独立的简体中文名称、明确规则、风味文案、稀有度、能力合同和本地 WebP 插画；有成长、衰减或轮换目标的奇牌会在夜市、卡包与牌桌显示已提交的当前值。

所有生产 ID 均使用 `bxqp:` 命名空间。旧 V1 至 V6 牌局会保留原有内容快照并前向迁移到 V7，不会被当前目录静默替换；奇牌的随机结果、每实例能力状态、档案归属与进度游标也随检查点、导出与导入保存。

开发时有两套独立审计页：

- <http://127.0.0.1:4173/?catalog-audit=1> 保留 230 项非奇牌分页总账。
- <http://127.0.0.1:4173/?catalog-audit=jokers> 显示 150 张奇牌，可按十五个班目和稀有度筛选；用 `&catalog-page=2` 可直接查看指定页。

两套页面都逐项显示简体中文身份、本地午夜百戏素材和独立焦点构图，不发起远程内容请求。奇牌原图来源、生成提示与人工审看记录保存在 `public/assets/jokers/provenance/`；布景与声场素材的权属记录保存在 `public/assets/presentation/provenance/`。
